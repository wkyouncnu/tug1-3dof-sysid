## 0. 지표 정의 — ★ 두 가지 ATE 가 있다

표에 따라 ATE 의 집계 방식이 다르다. 비교할 때 혼동하지 말 것.

| 출처 | ATE 정의 |
|---|---|
| `tug_eval.m` (§2, §3, §4) | **점 단위 평균절대오차**. 모든 창의 모든 시점을 동등하게 평균 → **긴 창이 지배한다** |
| `run_slx_val.m` (§6, §7) | **창 단위 RMS**. 창마다 RMS 를 낸 뒤 창을 동등하게 평균 |

같은 데이터에서 전자가 3.165 m, 후자가 2.450 m 로 나오는 이유가 이것이다.
51 초 지그재그 하나가 점 단위 집계를 끌어올린다. **두 수치는 모순이 아니다.**

공통 지표:

- `ζ = mean( rmse_χ / std_χ )`, χ ∈ {u, v, r} — 속도 3채널 정규화 복합지표
- `ATE/거리` — 창 하나당 평균 주행거리로 나눈 값. 길이가 다른 기동을 공정하게 비교
- `rmse_X, rmse_Y` 는 **창 시작 바디 프레임** 기준 변위 오차 ([`THEORY.md`](THEORY.md) §5.2)

### 읽는 법

**① 속도의존 추력 모델은 명확히 기각된다.**
`G`(선수 추진기 효율이 전진속도에 따라 감소)는 `rmse_r` 이 **0.121 → 1.780** 으로
**15배 악화**했다. `H`(+ 유효 모멘트팔 변동)는 `ζ = 432` 로 완전히 발산했다.
추가 자유도가 공선 방향으로 흘러들어가 최적화를 깨뜨린 것이다.

**⇒ 작용력은 PWM 룩업 + 상수 배분행렬로 끝난다. `l₃` 는 운동방정식에 없다.**

**② D 와 F3 의 차이는 실질적으로 없다.**
ζ 0.2935 vs 0.3077, ATE 0.513 vs 0.542 m. **구조가 다른데 궤적 성능이 같다** —
서로 다른 계수 집합이 같은 궤적을 만든다는 식별성 한계의 직접 증거다
([`THEORY.md`](THEORY.md) §5.3, §7).
F3 은 `m22 ≤ 3m` 물리상한을 걸었고 파라미터가 1개 적으며 `rmse_r` 이 더 낫다.
**기본값을 F3 으로 둔다. D 는 상한 없는 참조로 함께 보관한다.**

**③ 항을 3개 줄여도(Fs) 거의 손실이 없다.** 19항으로도 ζ 0.3165 다.
`Xvv`, `Xrr`, `Nvv` 의 기여가 작다는 뜻이고, 더 단순한 모델이 필요하면 Fs 가 출발점이다.

### 물리적 타당성 — 솔직한 평가

| 항목 | 관찰 | 판단 |
|---|---|---|
| `m11 = 17.86` | 선체질량에 고정 | 설계값 (surge 부가질량 0 가정) |
| `m22 = 53.6` (F3) / `119.0` (D) | 선체질량의 **3.0 / 6.7 배** | ⚠️ 부가질량만으로 설명 안 된다 |
| `m33 = 10.5` / `15.5` | 기하 추정 `I_z ≈ 1.78–3.33` 의 **5–7 배** | ⚠️ 같은 문제 |
| `Xu`, `Xuu` > 0 | 양수 (물리적으로 옳다) | ✅ |
| `Yvv`, `Yrr`, `Nvv`, `Nrr` < 0 | **2차 감쇠가 음수** | ⚠️ 비물리적. 선형항과의 상쇄로 들어갔다 |
| `X0`, `Y0`, `N0` ≈ 0.6–4.7 | 작지만 0 아님 | 추력 비대칭·정렬오차 흡수. 허용 |

**`m22`, `m33` 이 과대한 이유.** 추력 스케일 오차를 유효질량이 흡수한 것으로 보인다
([`THEORY.md`](THEORY.md) §5.3 의 축퇴). 추력이 실제로 작으면 같은 가속도를 내려면
질량이 커야 하고, 감쇠도 함께 조정되어 궤적은 맞는다. **계수의 물리적 해석은 유보해야 한다.**

**해결책은 계측이다.** 계류추력 시험(bollard pull) — 로드셀에 계류하고 PWM 을 스윕해
`PWM → N` 을 직접 재는 것. 물에 띄우기 전에 가능하고 투자 대비 효율이 가장 높다.
이것을 하면 `m22`, `m33` 이 물리적 범위로 내려올 것으로 예상한다.

**그러나 목적상으로는 문제가 없다.** 이 모델의 용도는 강화학습의 운동모델이고,
요구는 "같은 PWM 에 같은 궤적"이다. 그 요구는 §6–7 에서 충족된다.

### ★ 일반화 판정

**test 성능이 val 성능과 같거나 더 좋다.** 5초 창에서 test ζ(0.281 / 0.296)가
val(0.294 / 0.308)보다 낮고, 구간전체에서 F3 의 test ATE(3.109 m)가 val(3.163 m)보다 작다.

**과적합이 없다.** 분할 규칙이 각 기동 종류의 **가장 긴(= 진폭이 큰)** 기동을 test 로
보내므로([`METHOD.md`](METHOD.md) §5) test 가 더 어려운 조건인데도 성능이 떨어지지 않았다.
F3 이 구간전체 test 에서 D 를 앞선다(ζ 0.4314 vs 0.4433, ATE 3.109 vs 3.326 m) —
**더 단순한 모델이 외삽에서 더 낫다.** F3 를 기본으로 택한 근거의 하나다.

### 읽는 법

**속도오차는 N ≈ 25 (0.5 s) 에서 포화한다.** `u`: 0.185 → 0.214 (N = 25 → 150),
`r`: 0.122 → 0.100 (**오히려 감소**). **위치오차만 단조증가한다** (x: 0.075 → 0.514 m).

**⇒ 이것은 수치 불안정이 아니라 추측항법 적분 누적이다.**
속도가 포화한 상태에서 위치오차가 자라는 것은 `∫(속도오차)dt` 의 당연한 결과다.
모델이 발산하는 경우의 곡선은 속도오차도 함께 지수적으로 커진다 (§2의 `H` 가 그 예다).

**1-step 오차가 매우 작다** (`u` 0.017, 위치 0.004 m). 1-step 만 보고하는 관행이
왜 위험한지를 보여준다 — 롤아웃 오차는 그보다 10–30 배 크다.

(상대 0.524). 둘 다 저속·단거리 기동으로 `v` 추정 SNR 이 가장 나쁜 조건이다
([`THEORY.md`](THEORY.md) §5.4).

### 6.3 ★★ 지평 스윕 — 짧은 지평에서의 성능 (같은 Simulink PWM 모델)

`H` 초마다 재초기화한 창들의 집계. **강화학습 환경은 에피소드마다 초기화되고
제어기가 루프를 닫으므로 이쪽이 실제 사용조건이다.**

| F3 | **2** | 229 | 0.233 | 0.097 | 0.111 | 0.192 | 0.190 | 0.108 | **0.270** | 0.2918 |
| F3 | **5** | 83 | 0.236 | 0.152 | 0.118 | 0.621 | 0.486 | 0.292 | **0.789** | 0.3726 |
| F3 | 10 | 37 | 0.244 | 0.157 | 0.116 | 1.172 | 1.549 | 0.549 | 1.942 | 0.3814 |

## 7. ★ PWM 입력판 vs `tau` 입력판 — 같은 모델인가

식별 파이프라인은 PWM 을 50 Hz 격자로 보간한 뒤 `tau` 를 계산했고 `tug_sim` 은 RK4
중간스텝에서 `tau` 를 선형보간한다. PWM 입력판은 **PWM** 을 보간한 뒤 비선형 룩업을
통과시킨다. 순서가 다르므로 원리적으로 완전히 같을 수 없다.

**val 31개 전 구간에서 측정한 최대 편차:**

| mdl | Δu | Δv | Δr | **Δx[m]** | **Δy[m]** | Δpsi[rad] |
|---|---:|---:|---:|---:|---:|---:|
| D | 2.539e-03 | 1.244e-03 | 4.811e-03 | **2.179e-02** | 1.789e-02 | 2.488e-03 |
| F3 | 2.311e-03 | 8.161e-04 | 4.651e-03 | 1.177e-02 | **3.302e-02** | 4.111e-03 |

**최대 3.3 cm.** 궤적오차(미터 단위)보다 **두 자리** 작다.
**⇒ PWM 입력 Simulink 모델과 식별에 쓴 모델은 실용적으로 동일하다.**

## 8. 3자유도 근사의 타당성 (`roll_check.m`)

| 항목 | 값 |
|---|---|
| `corr(phi, r)` | **−0.9036** |
| pitch 평균 / 최대 | +5.71° / 22.68° |

**roll 은 yaw rate 와 거의 공선이다.** 4번째 자유도를 넣어도 독립정보가 거의 없고
`r` 과 다중공선이 되어 식별을 해친다. **roll 무시는 정당하다.**

**pitch 가 roll 보다 크다.** 추진기 작용점과 질량중심의 수직 오프셋이 가감속 중
pitch 모멘트를 만든다. 이것이 `forward_accdec` 가 상대적으로 불리한 이유의 일부로 보인다
(ATE 3.0–4.0 m, §6.2).

## 9. 추력 입력 쪽 사실

### 9.1 T200 곡선 (18.5 V)

| 항목 | 값 |
|---|---|
| PWM 격자 | 1200 : 4 : 1800 µs (151점) |
| 데드밴드 | [1476, 1528] µs (14 격자점, 추력 정확히 0) |
| 추력 범위 | **−29.4138 … +37.1093 N** |
| 정/역 비대칭 | 역추력 = 정추력의 **79 %** |
| 2차 모델 | R² = 0.99973, RMSE 0.266 N |

### 9.2 ★ 로그의 `tau` 는 작용력이 아니다

| 항목 | 값 |
|---|---|
| `max\|tauy_cmd\|` (143 로그 전체) | **0.000e+00** |
| 재구성된 실제 `tau_y` | **[−29.4, +37.1] N** |
| `corr(tau_y, tau_N)` | **0.959** |
| `corr(r, tau_y)` | 0.864 |
| 선수 추진기 포화 근접 비율 | 0.331 |

조종기에 sway 스틱이 없어 `Y` 입력이 Constant 0 으로 고정되어 있고, 그 결과
추력배분의 `Y == 0` 분기가 항상 선택되어 **선수 추진기가 모든 기동에서 주 yaw
구동기로 동작했다**. 로그의 `tauy ≡ 0` 과 실제 작용력은 전혀 다르다.

**이것이 이 식별의 가장 중요한 발견이다.** 로그의 `tau` 를 그대로 믿으면 완전히
틀린 모델이 나온다.

### 9.3 전압 검증 실패

`battery_status` 의 `voltage_v`, `voltage_filtered_v`, `current_a`, `remaining`,
`connected` 가 **전부 정확히 0** 이다. `current_average_a` 만 13.47–14.94 A 로 유효하다.

**⇒ 18.5 V 는 로그로 검증할 수 없다.** 사용자 진술에 의존한다.
전압이 실제로 달랐다면 추력 스케일이 틀리고, 그 오차가 §3 의 `m22`, `m33` 과대평가로
흡수되었을 가능성이 있다.

### 남은 한계 (정직하게)

1. **18.5 V 를 로그로 확인할 수 없다** (§9.3)
2. **`corr(tau_y, tau_N) = 0.959`** — sway 와 yaw 계수를 깨끗하게 분리할 수 없다.
   **순수 crabbing 기동**(`u ≈ 0, r ≈ 0, v ≠ 0`)이 필요하다
3. **`m22` 가 선체질량의 3–6.7배, `m33` 이 기하추정의 5–7배** — 부가질량으로 설명되지
   않는다. **계류추력 시험으로 `PWM → N` 을 직접 재야 한다**
4. **2차 감쇠항 일부가 음수** (`Yvv`, `Yrr`, `Nvv`, `Nrr`) — 비물리적. 선형항과의 상쇄
5. **roll/pitch 무시** — roll 은 정당하나(§8) pitch 는 가감속 기동의 잔류 오차원
6. **긴 개루프(> 40 s) 지그재그가 최악** — 선수방위 편향 누적. 폐루프에서는 문제되지 않는다
7. **추정기 SNR 민감도 스윕(`R = Q/SNR`)을 수행하지 않았다** — `v` 가 추정값이므로
   계수가 추정기 튜닝을 따라 움직일 수 있다 ([`THEORY.md`](THEORY.md) §5.4)

### 다음 단계로 권하는 순서

1. **계류추력 시험** — 3–4 를 한꺼번에 해결한다. 물에 띄우기 전에 가능하다
2. **순수 crabbing 기동 추가 수집** — 2 를 해결한다. 선수 추진기가 있으므로 가능하다
   (실현 한계 `Y_max ≈ 35.3 N`, [`THEORY.md`](THEORY.md) §3.3)
3. **질량·관성 실측** (`I_z` 는 비틀림 진자) — 3 의 교차검증
4. Tug 2 동일 파이프라인 적용 → **두 선박의 계수 일치도가 독립 교차검증이 된다**
